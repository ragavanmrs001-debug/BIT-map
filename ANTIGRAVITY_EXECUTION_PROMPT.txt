## LOCATION REQUIREMENTS

Create one shared location service.

It must provide:

- latitude
- longitude
- accuracy
- speed where available
- heading where available
- last update time
- distance travelled
- permission status
- tracking state

Both the 2D map and the 3D view must consume the same location state.

Do not implement separate GPS logic for 2D and 3D.

When the user moves:

- update the user marker smoothly
- update the 2D camera when Follow Me is enabled
- update the 3D camera when Follow Me is enabled
- keep manual exploration possible when Follow Me is disabled

Support both:
- Recenter on Me
- Follow Me

Do not constantly force the camera back to the user's position when Follow Me is off.

## GLOBAL LOCATION REQUIREMENT

Do not hard-code the location system to BIT.

It should work if the user travels to:

- another city
- another state
- another country
- another continent

The underlying geographic engine remains global.

BIT-specific information should activate primarily around the BIT campus.
